# Mamaearth Returns & Growth Intelligence Pipeline

**Program:** Data Analytics with AI & Gen AI — E&ICT Academy IIT Roorkee

## Project objective

Build a reproducible pipeline that loads relational order data, cleans
and analyses returns using pandas, and generates an SCR (Situation,
Complication, Resolution) business narrative using Gemini or an offline
fallback.

## Repository structure

- `sql/`: relational schema, seed-data instructions, loader, and reports
- `data/`: original customers, products, and orders CSV files
- `analysis/`: cleaning, EDA, outlier analysis, and visualization inputs
- `visualizations/`: generated PNG charts
- `narrator/`: generated findings, SCR narrative, and sample output

## Requirements

Python 3.10 or later is recommended.

Install dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
```

Place the three original, unmodified CSV files in `data/`:
`customers.csv`, `products.csv`, and `orders.csv`.

## Layer 1: SQL

From the repository root, run:

```bash
python sql/load_data.py
```

This creates `data/mamaearth.db`, loads all three CSV files, preserves
blank discount and rating values as SQL NULL, and verifies the row counts.

Expected counts:

- Customers: 45
- Products: 16
- Orders: 180

Run the SQL reports using the SQLite command-line tool:

```bash
sqlite3 data/mamaearth.db
```

At the SQLite prompt, execute:

```sql
.read sql/reports.sql
```

The reports demonstrate aggregation, NULL handling, joins, grouping,
HAVING, ranking, LIKE, DISTINCT, and ALTER TABLE with CASE.

The loyalty-tier ALTER TABLE statement is a one-time operation. If the
reports are rerun against the same database, skip that ALTER TABLE
statement once the column exists.

## Layer 2: Python analysis

Run:

```bash
python analysis/clean_and_eda.py
```

This script independently reads the original CSV files using pandas.
It standardizes payment methods, removes duplicate orders, imputes
missing values, reconciles revenue, flags quantity outliers, computes
return rates and correlations, and compares monthly revenue with and
without outliers.

The script writes:

- `analysis/payment_return_rates.csv`
- `analysis/monthly_revenue.csv`
- `narrator/findings.json`

The JSON file is generated from computed analysis results, not manually
maintained. Its verified figures feed the narrative layer.

Then run:

```bash
python analysis/visualize.py
```

This generates:

- `visualizations/return_rate_by_payment.png`
- `visualizations/monthly_revenue_trend.png`

The monthly chart uses outlier-corrected revenue.

## Layer 3: GenAI narrative

Run:

```bash
python narrator/generate_narrative.py
```

### Offline mode

If `GEMINI_API_KEY` is not set, the program generates a deterministic
SCR narrative from `narrator/findings.json`. No API key or network
connection is required.

### Optional Gemini mode

Set your Google AI Studio API key as an environment variable.

Linux/macOS:

```bash
export GEMINI_API_KEY="YOUR_API_KEY"
python narrator/generate_narrative.py
```

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="YOUR_API_KEY"
python narrator/generate_narrative.py
```

Use your own key and never commit it to the repository. The program
falls back to offline generation if the API call fails.

The script validates the five mandatory numeric findings and writes the
verified narrative to `narrator/sample_output.txt`.

## End-to-end run order

1. Preserve the source CSV files in `data/`.
2. Run `python sql/load_data.py`.
3. Run the SQL reports using the SQLite CLI.
4. Run `python analysis/clean_and_eda.py`.
5. Run `python analysis/visualize.py`.
6. Run `python narrator/generate_narrative.py`.

The SQL layer operates on the SQLite database. The pandas layer
independently reads the original CSVs. The narrator consumes the JSON
produced by pandas, maintaining the flow from verified analysis to
business communication.

## Data quality and limitations

The source data is synthetic capstone data, not verified company
transaction data. Return-rate associations are descriptive and do not
establish causation. Quantity outliers are flagged for analysis rather
than deleted from the cleaned dataset.

## Reproducibility

All derived outputs should be regenerated by the scripts. Do not
manually edit the source CSVs or hardcode generated findings.
